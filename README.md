# Nodirbek Zayniddinov — Portfolio

Personal portfolio of **Nodirbek Zayniddinov**, a 20-year-old Software Engineer based in Gettysburg, PA.

Live at → **[n1dlee.vercel.app](https://n1dlee.vercel.app)** *(deploy to Vercel to activate)*

---

## Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js 14 (App Router) |
| Language | TypeScript |
| Styling | Tailwind CSS v3 |
| Animations | Framer Motion |
| Icons | Lucide React |
| Fonts | Space Grotesk + DM Sans (Google Fonts) |
| Contact form | Formspree |
| Projects | GitHub API (server-side, 1hr cache) |
| Deploy | Vercel (zero-config) |

## Pages

- `/` — Hero, About, Contact
- `/work` — GitHub projects grid (live from API)
- `/about` — Full bio, skills, experience

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy to Vercel

1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → **New Project** → import this repo
3. Click **Deploy** — no environment variables needed
